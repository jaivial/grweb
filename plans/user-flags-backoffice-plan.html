1. Resumen de Roles y Permisos

Jerarquía de Roles

ROOT
Acceso TOTAL
Todos los competition IDs
ADMIN
Full access
Competition IDs asignados
STAFF
Sin Configuración
Competition IDs asignados
REGISTRADOR
Solo QR
Competition IDs asignados

Matriz de Permisos por Sección

Sección ROOT ADMIN STAFF REGISTRADOR
Dashboard ✓ ✓ ✓ ✗
Inscripciones ✓ ✓ ✓ ✗
Horarios ✓ ✓ ✓ ✗
Sorteo ✓ ✓ ✓ ✗
QR Reader ✓ ✓ ✓ ✓
Judge Table (FER) ✓ ✓ ✗ ✗
Configuración ✓ ✓ ✗ ✗
Gestión de Usuarios ✓ ✓ ✗ ✗
Reglas Importantes:
  • ROOT: Acceso automático a TODOS los competition IDs sin necesidad de asignación
  • ADMIN/STAFF/REGISTRADOR: Deben ser miembros de un competition ID para tener acceso
  • ADMIN: No puede cambiar el rol de otros usuarios con rol ADMIN
  • REGISTRADOR: Solo ve la sección QR, no tiene acceso a ningún otro menú

El solicitante tiene rol Staff o Registrador public async Task CanModifyUserRoleAsync(int requestingUserId, int targetUserId, int competicionId) { // Root puede modificar cualquier rol if (await IsUserRootAsync(requestingUserId)) return true; // Admin solo puede modificar Staff y Registrador, NO otros Admins if (await IsUserAdminOfCompetitionAsync(requestingUserId, competicionId)) { var targetRole = await GetUserRoleInCompetitionAsync(targetUserId, competicionId); return targetRole != UserRole.Admin; } return false; }

public async Task HasAccessToCompetitionAsync(int usuarioId, int competicionId) { var usuario = await _context.Usuarios.FindAsync(usuarioId); if (usuario?.IsRoot == true) return true; return await _context.UsuarioCompeticiones .AnyAsync(uc => uc.UsuarioId == usuarioId && uc.CompeticionId == competicionId); } public async Task GetUserRoleInCompetitionAsync(int usuarioId, int competicionId) { var usuario = await _context.Usuarios.FindAsync(usuarioId); if (usuario?.IsRoot == true) return UserRole.Root; var uc = await _context.UsuarioCompeticiones .FirstOrDefaultAsync(x => x.UsuarioId == usuarioId && x.CompeticionId == competicionId); return uc?.Role; }
